# MHO 素材メモ — モンハンアウトランダーズ

『モンスターハンターアウトランダーズ』(MHO) の必要素材を、狩る前に画面でメモしておくための非公式ファンメイドツールです。

> 🔗 **同じリポジトリの姉妹ツール: [MHO 依頼メモ (`requests.html`)](requests.html)**
> 匿名の依頼を「場所 → ターゲット」でメモするツールです。ヘッダの「依頼メモ」ボタンから切り替えられます。


- 単一の `index.html` のみで動作（ビルド・サーバー不要、ブラウザだけで完結）
- 外部への通信・データ送信なし（素材データは同梱）

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. 「モンスター → 素材 → レア度 → 必要数」をプルダウンで選んで「メモに追加」
3. 上部の「素材まとめ」に **素材×レア度ごとの合計個数** が表示される
4. 下の「メモ一覧」で数量を直接編集、☑ で確保済み、🗑 で削除

## 主な機能

| 機能 | 説明 |
|---|---|
| 3段プルダウン | モンスター → 素材 → レア度（Ⅰ〜Ⅵ）を選択。素材ごとに存在するレア度だけが選べる |
| 素材まとめ | 同じ素材×レア度を合算して必要数を一覧表示 |
| メモ一覧 | 数量の増減・直接入力、確保済みチェック（打ち消し線） |
| 自動保存 | メモと「素材管理」の追加分を localStorage に保存（再読み込みでも復元） |
| 素材管理 | 収録されていない素材を画面から追加・削除（例: 新モンスター・イベント素材） |
| バックアップ | メモとカスタム素材を JSON でエクスポート / インポート |
| テーマ | ダーク / ライト / ミント |

## 素材データについて

- 素材・モンスター・レア度の初期データは **MHO Hub（mhohub.com）の素材図鑑 / 素材検索** の公開情報を基にした参考情報です（2026-11 時点）。
- 非公式情報のため、**実際のゲーム内容と一致しない場合があります**。ゲーム内の表記・最新アップデートを優先してください。
- 収録されていない素材は、右上の **「素材管理」** から自由に追加できます（ブラウザの localStorage に保存）。
- データを更新したい場合は `index.html` の `MATERIAL_DATA` を編集します。

## 姉妹ツール: MHO 依頼メモ (`requests.html`)

匿名の依頼を「**場所 × ターゲット**」でメモしておくツールです。依頼をまとめて受けたあと画面を戻ると内容が分からなくなる、という悩みのためのものです。ヘッダの「依頼メモ」ボタンで切り替えられます。

### 使い方

1. `requests.html` を開く
2. 上の**クイック選択**をタップすると入力欄に入ります
   - **場所**: 主要4マップ（巨木の原野 / 熱砂の平原 / 朽ち果ての淵 / 瑰麗岩礁）
   - **ターゲット**: 依頼の種族（獣竜種 / 飛竜種 / 鳥竜種 / 魚竜種 / 牙竜種 / 古龍種 / 融光種）
   - **メモ**: 条件（近接武器 / 遠距離武器 / 捕獲 / 狩猟）を押すと入切（例:「近接武器・捕獲」）
3. そのまま「依頼を追加」。欄は自由入力もOK（モンスター名を直接入れてもOK）
4. 依頼は **場所ごとにまとまって表示**されます

### 依頼メモの主な機能

| 機能 | 説明 |
|---|---|
| クイック選択 | 4マップ・種族（〜融光種）・条件（近接/遠距離/捕獲/狩猟）をワンタップ入力 |
| 場所ごとのグルーピング | 同じ場所の依頼をまとめて表示。「残り N」バッジで進行状況が分かる |
| 完了チェック | ☑ で完了、「完了を隠す」トグル、「完了分を削除」 |
| テキストコピー | 依頼一覧を整形テキストでコピー（ゲーム内メモやチャット用） |
| 自動保存 / バックアップ / QR | 素材メモと同様（localStorage・JSON入出力・スマホ転送） |

### 依頼データについて

- マップ名（4エリア）と種族名は、公開 Wiki（Game8 / GameWith / MHO Hub 等）の情報を基にした参考情報です（2026-11 時点）。
- 匿名依頼は「マップ・条件・対象の種族」で指定されるため、ターゲットは種族名をクイック選択できるようにしています。一覧にない対象は自由入力してください。

## GitHub Pages で公開する

1. GitHub でリポジトリを作成して push
2. **Settings → Pages → Branch** で `main` / `(root)` を選んで Save
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

## 免責・注意

- 本ツールは非公式のファンメイドツールであり、カプコン / Proxima Beta および『モンスターハンターアウトランダーズ』とは関係ありません。
- データはブラウザの localStorage に保存されます。ブラウザのデータ削除で消えるため、必要に応じて JSON バックアップをご利用ください。
